Ruta recomendada para habilitar usuarios

  1. Depure primero correo, rol y alcance territorial.
  2. Para sincronizar las 46 credenciales oficiales, use Sincronización segura de las 46 credenciales. Ese flujo reemplaza la contraseña de cuentas existentes y crea las faltantes mediante Admin SDK.
  3. El JSON privado se cifra en el navegador antes de enviarse; las contraseñas no se publican en GitHub ni se almacenan en texto claro en Firestore.
  4. Las cuentas quedan listas para ingresar inmediatamente con la clave inicial indicada; no se envía correo de activación ni se exige cambio de clave al primer ingreso.
  5. El panel de provisionamiento por lote inferior queda disponible para validación y reconciliación ordinaria, pero no reemplaza una contraseña distinta ya existente.
  6. Antes de distribuir credenciales, confirme que el estado de sincronización indique SUCCESS · 46 de 46 verificados y ejecute la auditoría de perfiles.

Custodia: entregue cada clave solamente a su titular. No publique ni almacene archivos de credenciales en GitHub o repositorios compartidos.
