Administración y auditoría de perfiles

Esta página no crea contraseñas ni usuarios de Authentication. Vincula de forma verificable el UID de Firebase con su perfil y alcance.

Ingreso de administrador

Use una cuenta administrativa autorizada. La página rechazará cualquier otro correo.

Ruta segura para entregar una credencial

  1. Cree o revise el usuario en Firebase Authentication y copie su UID completo.
  2. Registre aquí el perfil usando exactamente ese UID y el mismo correo.
  3. Marque cambio obligatorio de clave y entregue la contraseña temporal por un canal individual.
  4. Pruebe en ventana privada: ingreso, cambio de clave, alcance visible y cierre de sesión.

No comparta contraseñas por correo grupal, WhatsApp grupal ni documentos. SmartRisk ya no almacena ni copia contraseñas temporales.

Detecta duplicados, campos faltantes, roles incompatibles y alcances incompletos.

Límite de esta auditoría

El navegador puede auditar Firestore, pero no puede listar ni administrar de forma segura todos los usuarios de Firebase Authentication. La conciliación completa Auth ↔ Firestore debe ejecutarse con Firebase Admin SDK o revisarse en la consola.
